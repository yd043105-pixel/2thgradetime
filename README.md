# 개인 시간표 조회 웹앱

2026학년도 2학기 시간표 PDF 2종과 학생 선택과목 배정 엑셀을 조합해, 학생 이름으로 개인별 주간 시간표를 조회하는 정적 웹앱입니다.

## 실행

PowerShell에서 이 폴더로 이동한 뒤 아래 명령을 실행합니다.

```powershell
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다. `npm start`도 같은 로컬 서버를 실행합니다.

## 포함 기능

- 학생 이름 검색과 동명이인 선택
- 본반 수업과 선택과목 구획/분반을 합친 주간 시간표
- 모바일에서 가로 스크롤 가능한 시간표 그리드
- 학생 시간표를 PNG 이미지로 저장

`src/data.js`에는 원본 파일을 분석해 생성한 조회 데이터가 들어 있습니다. 원본 파일이 수정되면 `tmp/build_schedule_data.py`를 다시 실행해 데이터를 갱신합니다.
